# dsh-dev-plugins — семейство самописных плагинов DeepSeek Harness

Создан 2026-11-05 словом хозяина. Здесь живут **самостоятельные git-репозитории
плагинов**, облегчающих workflow Помощника Мастера (пакеты `agents/П-NN`,
волны, почта, учёт токенов, приёмка).

Каждый плагин — **отдельный репозиторий**: своя версия (semver в
`package.json`), свои теги, свой `SOUL.md`, своя документация
(`README.md`, `ARCH.md`, `INTERNAL.md`, `CHANGELOG.md`), своя система сборки
(`make check`). Umbrella-каталог (это место) — только общая документация и
правила семьи; кода здесь нет.

## Правила семьи (обязательны для всех репозиториев)

1. **Один плагин — один репо — одна версия.** Semver: `0.1.x` — заготовка,
   `0.2.0` — первая рабочая версия (проверена на живом профиле), `1.0.0` —
   в боевой ежедневка. Тег `vX.Y.Z` ставится на коммит релиза.
2. **Документация локальна у плагина** (наша И2): `ARCH.md` — принципы и
   контракты (меняется только через комнату, метка `ARCH-CHANGE: RfI-NN`);
   `INTERNAL.md` — как устроено сейчас, в том же коммите, что код.
3. **`SOUL.md` плагина — фильтр решений**, когда инструкция молчит. Общий
   кодекс — `SOUL.md` этого каталога.
4. **Сборки нет намеренно**: хост-плагины — plain JS без transpile
   (канон харнесса, см. `docs/РАЗРАБОТКА.md`). «Сборка» = `make check`
   (синтаксис, манифест, locale, иконка, patч). Ненужный сборщик — долг.
5. **Установка — только через plugin manager** (`install_bundle` с абсолютным
   путём репозитория). Не править руками `cordis.patch.yml` профиля.
6. **Бережность к живому**: плагин пишет только в явно отведённые пути
   (конфиг), не трогает чужие сессии, не кидает новых типов событий в
   журнал сессии, не пишет токены/ключи никуда, кроме credentials.
7. **Честность версий**: в README и CHANGELOG не врать про статус; заготовка
   помечена заготовкой, «проверено» означает «проверено прогоном», остальное
   — «оценка».

## Как поставить плагин из этого каталога

Попросить агента (или в GUI: Настройки → Плагины):

> установи бандл `/home/vovan/Software/dsh-dev-plugins/<репо>`

под капотом: `plugin_manager install_bundle target=<абсолютный путь>`.
Новый бандл может активироваться через HMR; замена уже загруженного пакета
требует рестарта DSH. После установки — проверить `list_plugins` и
функционирование, а не только «строка появилась».

## Как завести пятый плагин

Скопировать любой репозиторий (например самый простой, `dsh-wave-gate-tool`),
переименовать пакет/строки/локаль/иконку, обнулить коды в `index.js` до
заглушки, `git init`, первая запись в CHANGELOG — `0.1.0 — заготовка`.
Проверить `make check` и этот README (таблица).

## Где смотреть API харнесса

`docs/РАЗРАБОТКА.md` — проверенные точки расширения (сервисы, события,
слоты, форма манифеста) по состоянию на 2026-11-05. Первоисточник — инспекция
живого харнесса (`cordis_inspect_list` / `cordis_inspect_query`), она же —
единственный арбитр, если这里的 текст разошёлся с кодом.
