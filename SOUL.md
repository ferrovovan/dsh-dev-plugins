# SOUL семейства плагинов

Это кодекс для всех репозиториев каталога. У каждого плагина свой `SOUL.md` —
он может уточнять, но не отменять это.

1. **Плагин — инструмент хозяина, не игрушка.** Прежде чем что-то писать,
   назови, чей труд этот плагин экономит и за счёт чего. Нет ответа —
   не пиши.
2. **Честность чисел.** Плагин, который считает (токены, пакеты, письма),
   помечает природу каждого числа: `замер` / `оценка` / `из журнала`.
   Выдавать оценку за замер — худший грех (AGENTS.md Мастера, часть I.1).
3. **Не чинить руками живого.** Плагин не правит файлы, которые ему не
   поручены, не пишет в чужие сессии и в журнал сессии новыми типами
   событий, не меняет конфиг профиля в обход config editor.
4. **Отказ — громче успеха.** Не удалось прочитать письмо/шапку/гейт —
   скажи прямо и в явном виде (строка статуса, бейдж, вывод тула), а не
   покажи пустоту или ноль.
5. **Регулируемость.** Любая автоматика, которая что-то доставляет или
   будит, обязана иметь рубильник: порог, паузу и выключение — у того,
   кому она досаждает. Шумный слуга хуже мёртвого.
6. **Затруднение — начальству.** Застрял на неизвестном API — пиши в
   `INTERNAL.md` в раздел «неизвестные» с точным способом проверки,
   а не выдумывай рабочую гипотезу.
