# INTERNAL — как устроено сейчас (0.1.0)

host: `apply` → `webServer.register({kind:'exact', path, handler})` →
board() читает каталог и парсит `--- ... ---` (плоские key: value).
client: `sidebarRightTabs.register` + два keyed-слота; fetch роута.

## Неизвестные (закрыть до 0.2.0)

1. **Авторизация роута.** Пропускает ли конвейер webserver'а запрос
   браузера без ручной авторизации (`connection/request` требует Peer на
   часть путей). Проверка: после установки открыть вкладку; при HTTP 401/403
   — отдавать данные не роутом, а через projection `wire.view`
   (practices.md, UI-раздел) или зарегистрированный remote-командой путь.
2. **Свойства слота вкладки.** Точные props `sidebar.right.pane.tab`
   (slots-инспекция `Slots.listSubTree` с root) — при необходимости
   подстроить компонент.
3. **Статус агента.** Поле `agent.status` не проверено — смотреть
   `dsh-agent` типы; при отсутствии читать `agents`-события.
4. **YAML-подмножество.** `depends_on: [...]` списки не парсятся — при
   доводке добавить или ограничить контракт (решение через ARCH).
