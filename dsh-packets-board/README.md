# dsh-packets-board — «Борт пакетов»

**Статус:** 0.1.0 — заготовка.
**Боль:** состояние очереди (кто какой П-NN, чья зона, чей бюджет, что
в работе) собирается глазами из `agents/README.md` + `list_agents`.

## Что делает

- **Хост:** роут `config.route` (по умолчанию `/api/master-packets`) с
  JSON: пакеты из YAML-шапок `agents/П-*/README.md` + список живых агентов.
- **Клиент:** вкладка «Пакеты» в правом сайдбаре (тип вкладки +
  keyed-слоты), автообновление 30 с, кнопки «Обновить». Цвета — токены
  темы.

Читает только `agentsDir` (read-only). Никаких записей.

## Установка / разработка

`install_bundle` с путём репо; `make check`. Чек-лист доводки —
`INTERNAL.md` (главное — авторизация роута и свойства слотов вкладки).
