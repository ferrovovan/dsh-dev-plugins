# ARCH — контракты плагина «Борт пакетов»

1. Источник данных — YAML-шапки пакетов (гейт П-61 — схема) и `ctx.agents`;
   плагин не вводит собственного состояния очереди.
2. Контракт роута (v1): `{generatedAt, packets:[{dir, package?, role?,
   zone_write?, status?, model?, budget_m?, ...}], agents:[{id,status}],
   error?}`. Поля пакетов прозрачны: новые поля шапок проходят как есть.
3. Клиент не складывает историю и не кэширует между сессиями.
4. Право на запись в дерево продукта у борта нет и не будет.
