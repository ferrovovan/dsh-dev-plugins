# AGENTS.md — указание агентам, работающим в этом каталоге

Это umbrella-каталог семьи самописных плагинов DeepSeek Harness.

1. **Стандарт семьи — [STANDART.md](STANDART.md).** Он обязателен: форма
   манифеста, структура репозитория, контракт `index.js`, регистрация тулов,
   честность статусов. Любой новый плагин или правка существующего — по нему.
2. Общий кодекс решений — [SOUL.md](SOUL.md); roadmap —
   [ПЛАН-РАЗРАБОТКИ.md](ПЛАН-РАЗРАБОТКИ.md); точки расширения харнесса —
   [docs/РАЗРАБОТКА.md](docs/РАЗРАБОТКА.md).
3. Каждый плагин — отдельный git-репозиторий (`/dsh-*/` в `.gitignore`);
   работай внутри нужного репо, umbrella-коммиты — только документация.
4. Арбитр расхождений — инспекция живого харнесса
   (`cordis_inspect_list` / `cordis_inspect_query`), затем исходники
   чек-аута, затем тексты.
5. Решения о включении плагинов, рестартах харнесса и боевом профиле —
   за Мастером. `make check` зелёный перед каждым коммитом.
